# Task 5 : Complex Analytical SQL Queries

A MySQL practice project based on student marks data, focusing on SQL window functions, CTEs, and aggregate functions.

## SQL Concepts Practiced
- `ROW_NUMBER()`
- `DENSE_RANK()`
- `LAG()`
- `LEAD()`
- `CTE`
- `CTE + DENSE_RANK()`
- `GROUP BY`
- `AVG()`
- `ROUND()`
- `PARTITION BY`
- `ORDER BY`

## Database
- **Database:** `Students`
- **Table:** `Student_info`

## Tools & Technologies

- MySQL
- MySQL Workbench
- SQL

## Key Learning Outcomes
- Applied window functions for ranking and sequential analysis.
- Used `LAG()` and `LEAD()` to compare student marks across records.
- Used CTEs to simplify complex queries.
- Calculated average marks using aggregate functions.
- Practiced ranking students within groups using `PARTITION BY`.
